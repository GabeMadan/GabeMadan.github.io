I then implemented iterative de-noising, where I created strided_timesteps, which started at 990 and decreased by 30 until it reached 0. I then applied to formula from the spec, and I got a much better approximation of the original image, as seen below.

Below is the code snippets for these images:

      
      a = alphas_cumprod[t]/alphas_cumprod[prev_t]
      b = (1 - a)

      x0 = (image - torch.sqrt(1-alphas_cumprod[t].to(image.device)) * noise_est) / torch.sqrt(alphas_cumprod[t].to(image.device))
      a1 = alphas_cumprod[t].to(image.device)
      a2 = alphas_cumprod[prev_t].to(image.device)
      img = torch.sqrt(a2) * b / (1 - a1) * x0 + torch.sqrt(a) * (1 - a2) / (1 - a1) * image

Next, I implemented CFG according to the algorithm described in the spec. I did this by running the UNet twice, and then combining the noise amounts. I then added conditional variance to the output, and resulting images were much better quality then the diffusion model sampling images. Below is a code snippet for this section 

    

      noise_est, predicted_variance = torch.split(model_output, image.shape[1], dim=1)

      cfg = uncond_noise_est + scale * (noise_est - uncond_noise_est)

1.8: Visual Algorithms

To make a visual anagram, I repeated a similar process above, but each iteration, I flipped the image once and generated an image for a given prompt for the right-side up image, and also generated an image for a different prompt for the upside-down version of the image. Below is a snippet of the code:

          

      cfg = uncond_noise_est + scale * (noise_est - uncond_noise_est)
      cfg_flipped = uncond_noise_est_flipped + scale * (noise_est_flipped - uncond_noise_est_flipped)
      cfg_flipped = torch.flip(cfg_flipped, dims=(2,))
      cfg = (cfg + cfg_flipped) / 2

1.9: Hybrid Images

To make hybrid images, I combined the low freq noise which was predicted from the first prompt with the high freq from the other prompt at each iteration step. Then, I used that combined noise to guide the denoising process, as done before. Below is a few lines of my code which do this

        

      uncond_model_output1 = stage_1.unet(image, t, encoder_hidden_states=uncond_prompt_embeds, return_dict=False)[0]
      n1, var = torch.split(model_output1, image.shape[1], dim=1)
      uncondn1, _ = torch.split(uncond_model_output1, image.shape[1], dim=1)
      cfg1 = uncondn1 + scale * (n1 - uncondn1)

      uncond_model_output2 = stage_1.unet(image, t, encoder_hidden_states=uncond_prompt_embeds, return_dict=False)[0]

      uncondn2, _ = torch.split(uncond_model_output2, image.shape[1], dim=1)
      cfg2 = uncondn2 + scale * (n2 - uncondn2)

      low = TF.gaussian_blur(cfg1, 33, 2)
