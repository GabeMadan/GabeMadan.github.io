        def conv(img_path, k):
            img = cv2.imread(img_path, cv2.IMREAD_GRAYSCALE)
            cv2.imwrite("out/img1original.jpg", img)
            iheight, iwidth = img.shape
            kheight, kwidth = k.shape
            final = np.zeros_like(img)
            padding = np.pad(img, ((kheight//2, kheight//2), (kwidth//2, kwidth//2)))
            for a in range(iheight):
                for b in range(iwidth):
                    conv_val = 0
                    for i in range(kheight):
                        for j in range(kwidth):
                            conv_val += padding[a+i, b+j] * k[i, j]
                    final[a, b] = conv_val

            return final

        def conv_2loops(img_path, k):
            img = cv2.imread(img_path, cv2.IMREAD_GRAYSCALE)
            cv2.imwrite("out/img1original.jpg", img)
            iheight, iwidth = img.shape
            kheight, kwidth = k.shape
            final = np.zeros_like(img)
            padding = np.pad(img, ((kheight//2, kheight//2), (kwidth//2, kwidth//2)))
            for a in range(iheight):
                for b in range(iwidth):
                    temp = padding[a:a+kheight, b:b+kwidth]
                    final[a, b] = np.sum(k*temp)
            return final

Part 2.1: Image sharpening

To sharpen the following image, I first used a low pass filter to find all the low frequencies in the image. To do this, I performed a convolution of the image with a 5x5 kernel of 1s. The, to get the high frequencies in the image, I just subtracted the low frequencies from the original image using cv2.subtract. Lastly, I then added the high frequencies in the image back to the original image to make it appear sharper. A frequency multiplier of 1 worked well for me, as seen below. To combine all these steps into a single convolution operation, I started with the equation Ilow = I * b, where b is the blurring kernel. Then, we plug this into the formula for the image Isharp = I + a*Ihigh, which gives the equation Isharp = I + a*(I - Ilow). Next, we can replace the Ilow with I * b and then expand this formula to Isharp = (1 + a)*I - a(I * b). Lastly, to rewrite the image as a convolution, we can multiply all this by an impulse kernel to transform the formula into a convolution. Thus, Isharp = (1 + a)*I*k - a(I * b). Lastly, we can factor out the I, giving us Isharp = I * ((1 + a)k - ab).

Part 2.3: Gaussian and Laplacian Stacks

To create a Laplacian stack, I first created a Gaussian stack, where I blurred the images with a Gaussian filter at different levels. Then, I subtracted each tier of the Gaussian stack from the tier above it, and these differences form a Laplacian stack. The last level is just the most blurry Gaussian image, since there isn't any frequencies left to subtract away. By this logic, the Laplacian stack gets all of the high frequency details near the top tiers of the stack and all the lower frequency information at the lower tiers.
