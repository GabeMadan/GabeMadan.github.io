Part A.2: Recover Homographies

We start with the equation p' = Hp. Below are the correspondences visualized on the images:

I solved for the system of equations by setting up the equation p' = Hp, with H being a matrix that contained values h1, h2, ... h9. h9 = 1, since its the scaling factor. Then, I set p = [x, y] and p' = [x', y']. I then added an extra dimension of 1 to p and p' such that the matrix multiplication would work out. From there, I expanded the multiplication on the right side of the equation, then rerarranged it such that I got two equations which were linear in x' and y'. These equations were xh1 + yh2 + h3 - xx'h7 - x'yh8 - x' = 0 and xh4 + yh5 + h6 - xy'h7 - yy'h8 - y'h9 = 0. Then, we can extract all the h values, such that we have [x, y, 1, 0, 0, 0, -xx', -xy', -x'] * h = 0 and [0, 0, 0, x, y, 1, -xy', -yy', -y'] = 0. This applies for any two corresponding points.

Part A.4: Blending

To blend two images together to create a mosaic, I used the Nearest Neighbor interpolation from the previous part. First, I hand selected corresponding points in each section of images which overlapped. Next, I used the interpolation to warp one image into the coordinate space of the other using the computed homography. Then, I blended the overlapping regions using a weighted average, where alpha is 1 at the center of each image and falls off linearly until it gets to 0 near the edges. There are some minor artifacts even after smoothing, but I think this is because of two reasons: firstly, my images were not perfectly rotated around a singular point, as its difficult to keep the camera perfectly still in space and rotate it. Secondly, my images have a lot of detail in them such as leaves and grass, and therefore, any slight misalignment is noticable. However, I think the final product looks pretty good considering the images were taken by hand.

Part B.1: Harris Corner Detection

To do Harris detection, I first converted the image to grayscale and then found the Harris corner response for each pixel. This detects points where the intensity within a patch changes sharply, which indicates a corner. I also implemented ANMS, which keeps the best points by enforcing the minimum distance between points. This outputs a smaller set of better feature points.

Part B.2: Feature Descriptor Extraction

For feature descriptor extraction, I extracted different patches of the image by looping through each Harris corner and cropping a 40x40 pixel region centered on that point. Then, I downsampled each cropped patch to 8x8 pixels. Below are the patches, as well as the original image with the location of each patch.

Part B.3: Feature Making

I compared the 8x8 patches using their eucliedean distances. For each patch in the first image, I found its two closest matches in the second image. A match was only kept if the best distance was a lot smaller than the next best distance (by a factor of 0.7). Also, the outlier points which are not properly corresponding between the two images will be filtered out in the next part.

Part B.4: RANSAC

I implemented 4-point RANSAC as follows. First, I randomly selected 4 matching points, and from these I found the homography from these points. Then, I projected all the points from the first image using the homography, and kept track of their error to their corresponding points in image 2. I repeated this process 500 times, each time checking how many pairs have an error of less than 5 pixels. I did this process on the same three images that I did the manual matching on from part A. For some, it worked better than others, as seen below.

In the above dinosaur image, the two methods seem to be very similar, and I couldn't notice much difference between the two results.

In the above VLSB image, the two methods seem to have similar results, but I do see a slight difference. The RANSAC method has the grass detail a bit more clear, whereas the manual method has the details on the building pillars a bit more clear.

The last observation I want to make is regarding the following image, my 3rd panorama. I had hypothesized that this image set would work well with RANSAC since it has so much detail in the leaves and there are so many potential points to map from image 1 to 2. This turned out to be the case, but the issue with so much information is that its also very easy to visually tell when the image is even slightly misaligned. So, if my hands were even a centimeter tranposed between when I took image 1 and 2 for this panorama, the difference is made mmuch more clear in an image which has so much fine detail like this one. I noticed this issue in many of my pictures which had grass or leaves in them. In general, I think that whether implemented manually or with RANSAC, panoramas benefit from having less fine detail and a lot of straight edges and corners rather than round curves.
